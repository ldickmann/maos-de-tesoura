# Instruções para o Claude Code

## Link da sessão do Claude Code

Nunca inclua o link da sessão do Claude Code (`https://claude.ai/code/session_...`) em nada que vá para o
GitHub:

- título ou descrição de pull request;
- comentário, review ou resposta em pull request ou issue;
- mensagem de commit (não use a linha `Claude-Session:`).

Depois de criar um pull request, leia a descrição publicada e, se algum link de sessão tiver sido acrescentado
automaticamente (por exemplo, num rodapé "Generated by Claude Code"), edite a descrição e remova-o.
